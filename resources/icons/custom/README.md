# Custom symbolic icons

Drawn for Gear Lever COSMIC where the pinned cosmic-icons set has no icon of
that name. Same 16x16 grid and #232323 fill as cosmic-icons, so the symbolic
recolouring treats them alike. License: GPL-3.0-or-later, like the app.

`ci/vendor-icons.py` copies every SVG here into
`resources/icons/GearLeverCosmic/scalable/actions/` after the cosmic-icons.

- view-app-grid-symbolic.svg: 3x3 dots (Installed Apps)
- view-list-symbolic.svg: three list rows
